# 🎬 Galeria de Vídeos (Estilo YouTube)

Este projeto é uma página simples em **HTML + CSS** que simula uma galeria de vídeos semelhante à interface do YouTube.  
Ideal para treinar **HTML, CSS, responsividade** e aprender a publicar sites no **GitHub Pages**.

## 💻 Rodando localmente

Baixe ou clone este repositório:

git clone https://github.com/SEU_USUARIO/site_youtube_css.git

Entre na pasta do projeto:

cd site_youtube_css

Abra o arquivo index.html no navegador.

## 🌍 Publicando no GitHub Pages

Faça o push deste projeto para o seu repositório no GitHub.

Vá em Configurações > Pages.

Em Source, selecione a branch main (ou master) e a pasta / (root).

Clique em Save.

O site ficará disponível em:

https://SEU_USUARIO.github.io/site_youtube_css
